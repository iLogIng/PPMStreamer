# PPMStream Project
> **VERSION 0.0.1**
> **2025.12.01**

## 项目目的

- 该项目是为了学习计算机图形学而设计的一个PPM文件的文件读写流项目。
- 该项目是为了给图形学算法提供一个编写的实践平台。

---

## 文件结构

### 数学库

- **Vec.hpp**
    > 向量
- **Mat.hpp**
    > 矩阵

### 图形建模

- **Point.hpp**
    > 点
- **RGB.hpp**
    > 像素rgb

### 读写流

- **PPMStream.hpp**
    > ppm文件读写流
- **PPMBuffer.hpp**
    > ppm文件读写缓存
